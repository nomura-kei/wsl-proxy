# WSL プロキシ環境

WSL 上の Linux のプロキシ設定をすべて、
http://127.0.0.1:3128
で統一できるようになります。

プロキシサーバーの変更や、
他ネットワークに WSL を移植する際も便利かと思います。

# インストール
install.bat を実行してください。
※途中、管理者権限が必要です。


# 設定

# 1. 共通
# conf/squid.conf の最後の行付近
(1) 必要に応じて、dns_nameservers に DNS サーバーを指定してください。

# 2. 親プロキシサーバーを利用する場合
(1) conf/proxy.conf ファイルに親プロキシサーバーの設定を記載ください。

# 3. 親プロキシサーバーを利用しない場合
(1) conf/squid.conf の最後の方にある、次の2行を削除してください。
- never_direct allow all
- never_direct allow CONNECT


# 起動
start.bat を実行してください。

※設定変更後も、start.bat を実行で設定が反映されます。


# アンインストール
uninstall.bat を実行ください。


# 仕組み
- Alpine の squid にてプロキシを実現しています。
- ポートプロキシにより、3128 番ポートを公開しています。
=> これにより、Windows 及び、他の WSL から、http://127.0.0.1:3128/ にてプロキシを利用可能となります。
